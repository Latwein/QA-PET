BR-001 — No tooltip displayed on "Favorites" and "Compare" icons in header

Preconditions: User is on the main page.

Steps to reproduce:

Open https://www.poehalisnami.kz/

Hover over the "Favorites" (heart icon) in the header

Hover over the "Compare" (scales icon) in the header

Hover over the "Login" button

Expected result:
Tooltips are displayed for all header action icons, ensuring consistent user experience.

Actual result:
Tooltip is displayed only for the "Login" button.
No tooltip appears for "Favorites" and "Compare" icons.

Environment:
Windows 11, Yandex Browser 26.3.0.2166 (64-bit), Desktop

Severity: Low

Priority: Low

Notes:
Missing tooltips on some header icons create inconsistent UX and may reduce usability, especially for new users unfamiliar with icon meanings.
