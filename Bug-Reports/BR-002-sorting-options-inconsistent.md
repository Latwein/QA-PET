BR-002 — Sorting options are inconsistent across destinations (Vietnam vs Thailand)

Preconditions: User is on the tour search page.

Steps to reproduce:

Open https://www.poehalisnami.kz/tour

Select destination Thailand

Click Search for a tour

Open the sorting dropdown and note available options

Repeat the same steps for destination Vietnam

Expected result:
Sorting options are consistent across destinations, or differences are clearly explained to the user.

Actual result:
For Thailand, the dropdown contains: by price, by rating, recommended.
For Vietnam, the dropdown contains only: by price.

Environment:
Windows 11, Yandex Browser 26.3.0.2166 (64-bit), Desktop

Severity: Low
Priority: Medium

Notes:
Inconsistent sorting options may confuse users and create the impression of missing or unavailable functionality.
