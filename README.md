# QA Bug Reports Portfolio Latwein

This repository contains a structured QA testing portfolio demonstrating manual testing skills, bug reporting practices, and documentation standards based on real-world UI issues observed in public web applications.

---

## Project Overview

The purpose of this project is to demonstrate practical knowledge of QA processes, including:

- Manual testing of web applications
- Identification and reporting of UI/UX defects
- Writing clear, reproducible bug reports
- Providing visual evidence through screenshots
- Using Git and GitHub for version control and documentation

---

## Scope of Testing

Testing activities focused on the following areas:

- User interface consistency
- Navigation behavior and redirects
- Button and link functionality
- Layout and interaction issues

---

## Bug Reports

Each bug report in this repository follows a structured format and includes:

- Unique bug identifier (BR-XXX)
- Clear and descriptive title
- Steps to reproduce
- Expected result
- Actual result
- Environment information
- Attached screenshots for verification

### Reported Issues

- BR-001 — Tooltip is not displayed on hover
- BR-002 — Sorting options behave inconsistently across views
- BR-003 — Google Play button redirects to Apple App Store instead of Google Play Store

---

## Evidence

All screenshots related to bug reports are stored in the `screenshots` directory and referenced directly within each report for traceability.
